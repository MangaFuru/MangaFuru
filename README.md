# GoMangaApp

This repository is the public issue intake surface for GoManga app reports.

## Report a Problem

Use the GitHub Issues page:

https://github.com/go-manga/GoMangaApp/issues

Click **New issue**, choose **GoManga bug report**, and fill in the template. The public support page can help you prepare the details before posting:

https://go-manga.github.io/support.html

## Report Template

Use the GitHub issue form whenever possible. If you need to prepare the report elsewhere first, use this structure:

```markdown
### Summary

### Area
Reader / Manga Detail / Library / Lists / Sources / Downloads / Settings / Launch / Other

### App version

### iOS / iPadOS version

### Device

### Steps to reproduce
1.
2.
3.

### Expected result

### Actual result

### Frequency
Always / Often / Sometimes / Once

### Screenshots or diagnostics
Remove secrets and personal information before attaching anything.
```

## Before Posting

- Include the app version, iOS/iPadOS version, device model, affected area, expected result, actual result, and steps to reproduce.
- If the issue involves a source, include only public source or host information.
- Do not post passwords, private tokens, full cookies, paid content, personal information, or private diagnostic data.
- Screenshots and diagnostics are useful, but review them before attaching them to a public issue.

## What Belongs Here

- App bugs
- Reader behavior problems
- Library, Lists, Settings, Sources, and Repositories workflow issues
- Reproducible crashes or performance problems
- Documentation gaps in the public GoManga site

## What Does Not Belong Here

- Manga content requests
- Source recommendations or source indexes
- Requests to bypass login, payment, access controls, or regional restrictions
- Private credentials, cookies, tokens, or paid content

GoManga does not host manga content. Sources, files, accounts, and access rights are configured and managed by the user.
