# GoMangaApp Support

Static GitHub Pages support site for GoManga bug reports and issue intake.

## Files

- `index.html` - guided issue report form.
- `assets/support.css` - support site styling.
- `assets/report.js` - builds a GitHub issue URL from form fields.
- `.github/ISSUE_TEMPLATE/bug_report.yml` - native GitHub issue form.

No build step is required. GitHub Pages can serve the repository root directly.
